# Kid Games - Development Guidelines

## Project Overview

This is a collection of web-based games for kids, hosted on GitHub Pages.

## Adding New Games

When you create a new game, you **must** update `index.html` to include a link to it.

### Game Structure

Place each game in its own directory:
```
/games/
  /game-name/
    index.html
    (other assets)
```

### Updating index.html

After creating a new game, add a link to it in the main `index.html` file so users can navigate to it from the landing page.
